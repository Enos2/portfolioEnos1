# Portfolio Website

This is a portfolio website that showcases my work and skills as a software engineer. The website has the following sections:

- Home Page
- About Me Page
- Blog Page
- Contact Me Page
- Portfolio Page
- Download CV

## Built With

The website is built with the following technologies:

- HTML
- CSS
- JavaScript

The website is hosted on Firebase.

## Getting Started

To get a copy of this project up and running on your local machine, follow these steps:

1. Clone the repository to your local machine:

```sh
git clone https://github.com/Enos2/portfolioEnos1.git
```

2. Navigate to the project directory:

```sh
cd portfolio-website
```

3. Install the project dependencies with npm:

 ```sh
 npm install
 ```

4. Run the project locally:

 ```sh
 npm start
 ```

Note: Replace `[USERNAME]` with your GitHub username.
